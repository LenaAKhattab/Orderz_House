# Brand assets

- `company_logo.png` — official Orderz House mark (transparent; for in-app auth headers).
- `full_logo.png` — full vertical logo (mark + Arabic wordmark + tagline) from `frontend/public/hero/fullLogp.png`; used on splash.
- `app_icon.png` — launcher icon (same mark on white background).
- `splash_mark.png` — Android splash drawable source.

Used via `AppBranding.logoAsset` / `AppBranding.fullLogoAsset`.
Launcher icons generated from `app_icon.png` via `flutter_launcher_icons`.
