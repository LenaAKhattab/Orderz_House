# OrderzHouse terminology

Arabic is the source of product meaning; English is the second semantic reference. One term per concept per
language — every page, button, email and notification uses the same word. Plural forms in brackets.

## Tone

| Locale | Address | Buttons / actions | Notes |
| --- | --- | --- | --- |
| de | formal **Sie** | infinitive: *Speichern*, *Auftrag erstellen* | nouns capitalised; prefer compounds over "von"-chains; concise labels |
| nl | formal **u** (Netherlands Dutch) | infinitive: *Opslaan*, *Opdracht plaatsen* | no German-style constructions; *u/uw* consistently |
| ro | formal (**dumneavoastră**, imperative *-ți*: *Salvați*, *Trimiteți*) | imperative formal | always comma-below **ș ț** (never cedilla ş ţ); correct ă â î |

## Names that are never translated

OrderzHouse / Orderz House · FAZAAT · Bildazo · Stripe · WhatsApp · plan names **STARTER, SILVER, PRO, ELITE**
(keep the casing of the English source) · currency code **JOD** · internal codes (`annual_basic`, status codes,
error codes). Visible plan qualifiers are translated: "Annual SILVER" → *SILVER Jahrespaket* / *SILVER jaarpakket* /
*SILVER anual*.
